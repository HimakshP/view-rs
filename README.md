# view-rs

A lightweight, reusable SVG viewport engine written in Rust and compiled to WebAssembly. Provides interactive map navigation through viewport transformations, allowing applications to pan, zoom, and navigate SVG-based interfaces with precise coordinate handling.

Originally built as a reusable component for **Campus-Nav**.

### Current Functionalities
- Interactive SVG viewport management
- Pan and zoom transformations
- SVG-to-viewport coordinate transformations
- Viewport state management
- Rust implementation compiled to WebAssembly
- Reusable architecture for SVG-based applications

### Future Scope
- Smooth animated transitions
- Configurable zoom limits and viewport constraints
- Touch and multi-pointer gesture support
- Improved rendering and interaction performance
- Reusable event and interaction APIs
